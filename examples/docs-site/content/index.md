# Documentation Site Example

Welcome to the documentation site example built with Doki Engine!

## What is This?

This is a documentation site example demonstrating how to use Doki Engine to create a comprehensive documentation site with multiple sections and navigation.

## Documentation Sections

- [Quick Start](quick-start) - Get started with Doki Engine
- [Installation](installation) - How to install Doki Engine
- [Usage](usage) - How to use Doki Engine
- [API Reference](api-reference) - API documentation for Doki Engine

## Features

- **Multiple Documentation Sections**: Organized documentation with clear navigation
- **Markdown Support**: Write documentation in Markdown format
- **Template System**: Consistent layout using Dejavu templates
- **Static Site Generation**: Fast and efficient static site generation
- **Responsive Design**: Mobile-friendly documentation

## Getting Started

1. **Install Dependencies**
   ```bash
   pnpm install
   ```

2. **Build the Documentation**
   ```bash
   pnpm build
   ```

3. **Serve the Documentation**
   ```bash
   pnpm serve
   ```
