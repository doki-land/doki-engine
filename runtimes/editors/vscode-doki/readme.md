# 💻 Doki VS Code Extension

Official VS Code extension for Doki / Dejavu templates.

## ✨ Features

- 🎨 Syntax highlighting
- 💡 Completions (keywords, variables, filters, snippets)
- 🔍 Live diagnostics
- 📖 Hover info
- 🔗 Go to definition
- 👁️ Template preview
- ⚡ Quick fixes
- 📊 Inheritance awareness

## 📦 Install

Search **Doki** in the VS Code Marketplace, or build from source:

```bash
cd runtimes/editors/vscode-doki
pnpm install
pnpm run package
```

Install the generated `.vsix`.

## 🚀 Supported files

| Extension | Language ID |
| --- | --- |
| `.doki` | `doki` |
| `.dj` | `doki` |
| `.dejavu` | `dejavu` |

Open a template file — highlighting and language features activate automatically.
