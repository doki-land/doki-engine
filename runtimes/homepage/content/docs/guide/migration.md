## Keep the archive

Doki migration tools read the formats you already have and move the durable parts into Markdown, frontmatter, images, and data files. The original archive remains available while you review the new output.

## A deliberate path

1. Export the source archive.
2. Map its posts, pages, and media into a Doki content folder.
3. Choose a DejaVu theme and compare the rendered output.
4. Publish the generated static files when the new surface is ready.

The goal is a portable source tree, not another platform lock-in.
